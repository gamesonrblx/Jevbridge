# Contributing

Contributions that improve Jevbridge are welcome.

1. Read this file and the [Code of Conduct](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
2. Fork the project.
3. Create a focused branch: `git checkout -b feature/short-description`.
4. Add or update tests for behavioral changes (`src/*.test.ts`).
5. Run `node --experimental-strip-types --test src/*.test.ts src/**/*.test.ts`.
6. Open a pull request.

By contributing, you agree that your contribution is provided under this repository's MIT License.

Do not commit API keys, customer data, or live TypeSafe / LLM credentials.
